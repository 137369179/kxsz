## 0. 核心框架总览

```text
┌─────────────────────────────────────────────────────────────┐
│  编码 Encoding                                               │
│  multimodal（13 模态）· morph/字源 · 拼音 · 语义 · 动觉描红   │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  存储 Storage                                                │
│  FSRS 混合调度（√S + 年龄缩放）· 同日复习温和惩罚 · 每日时长限 │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  提取 Retrieval  【当前最大产品缺口】                          │
│  现状：Drill /「练」以再认（MC）为主                            │
│  缺口：自由提取闪卡 · 形近字交错包 · 生成式自我解释              │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  元认知 / 时机 / 心流  【多为死代码或文案，未成产品环】          │
│  microReviewScheduler 无 call site · realtimeAdjust 未调用   │
│  睡前巩固仅文案 · JOL 不存在 · 每日上限是门禁非庆祝页            │
└─────────────────────────────────────────────────────────────┘
```

**一句话判断**：项目在「编码 → 存储」骨架上已强于多数识字 App；瓶颈不在再接一套算法，而在把**提取练习**做实，并把已有但半接线的引擎（flashcard / sessionPlanner / difficulty / microReview）收成产品环。

## 1. 现有功能分析（学习记忆机制视角）

### 1.1 已落地且有研究依据的强项

| 机制 | 实现（代码事实） | 研究依据 |
|------|------------------|----------|
| 间隔重复 | `ebbinghaus.completeCharacter/completeReview` → `fsrsCompleteCharacter/Review`；含同日复习检测与年龄间隔缩放（`getDecayForAge` / `scaleIntervalForAge`） | Ebbinghaus；FSRS 族算法 |
| 多感官双重编码 | `multimodalEngine.MODALITIES`：**13** 个冻结键（字形/emoji/时间线/拼音/口诀/例句/义/词/易混/动觉×3/游戏） | Paivio 双重编码 |
| 工作记忆块化（部分） | `sessionPlanner.AGE_SESSION_TABLE`（如 4 岁 2 新+2 复习；6–8 岁 3+4）；Review 用到部分配置 | Miller / Cowan |
| 年龄自适应步骤 | `getStepSequence`：`<5 → [1,2,4,8]`；`<7 → [1,2,4,5,6,8]`；否则满 8 步 | 皮亚杰前运算期约束 |
| 认写分流 | Step5 控笔 → Step6 描红 → Step7 写（`prewriteEngine` / `hanziEngine`） | 先认后写铁律 |
| 形音义三位一体 | morph/字源剧场 + 拼音 + meanings/组词（`morphEngine` / `etymologyEngine` / learnSteps） | 汉字三维表征 |
| 阅读分级 | `readingGatekeeper` + `bookHub/bookShelf`（BLOCKED / PARTIAL / READY） | 可理解输入 i+1 |
| 正向情绪保护 | `stepRead` 低分归因「麦克风没听清」+ 失败脚手架 | 班杜拉自我效能 |

### 1.2 原稿易误判处（排期前必读）

| 常见说法 | 代码现实 | 排期含义 |
|----------|----------|----------|
| 「已跑完整 FSRS-6 闭式间隔」 | **PARTIAL**：有 21 权与 R/S API；生产间隔主路径仍是 **√stability + 年龄缩放**，不是 `calculateIntervalFSRS6` 主导 | 勿再排「接上 FSRS」；若要闭式 I(S,R) 需单独立项 |
| 「测步骤 = 测试效应」 | **WRONG**：Step8「测」是**结业庆祝发星**（`stepTest.js`）；再认练习在 Step4「练」/ `DrillEngine` | 自由提取**不是**改 Step8，而是新复习形态 |
| 「sessionPlanner 已驱动每日学练」 | **PARTIAL**：年龄表存在；`planDailySession` **无 UI 调用** | P0 交错可顺带接线，勿假设已生效 |
| 「每日上限庆祝页可挂睡前 CTA」 | **WRONG**：`ensureDailyLimitAllowsStudy` = **家长门禁 + toast** | 睡前入口需另找挂点（如 Map/家长页/复习入口） |
| 「实时动态难度已有」 | **PARTIAL**：`difficultyEngine.realtimeAdjust` 存在，`drillEngine` **import 但未调用** | P1 优先「接线」而非重写 |
| 「睡前/次日巩固已有」 | **MISSING**：家长文案 + TTS emotion；`microReviewScheduler` **无 call site** | P1 产品环，非文案优化 |
| 「形近字交错已系统化」 | **PARTIAL**：`confusingChars` + `reviewConfused` 入队/作干扰项；**无**专项交错练习包 | P0 玩法层即可 |

### 1.3 覆盖度缺口（相对记忆研究图谱）

| 机制 | 现状 | 缺口 |
|------|------|------|
| 测试效应（Testing Effect） | 「练」为再认 MC；`flashcardEngine` 有 recall 类型但 Review 仍跑 Drill | 缺强制「先回忆再验证」的自由提取 UX |
| 生成效应（Generation Effect） | 字源是「讲给孩子听」 | 缺「你觉得像什么」自我解释 |
| 交错练习（Interleaving） | 混淆字作干扰项 / 队列注入 | 缺形近字专项交错包（双方均已学才开） |
| 元认知（Metacognition / JOL） | 无 | 缺「很熟 / 有点忘 / 不记得」自评 |
| 情绪+睡眠巩固 | 正向反馈有；睡前文案有 | 缺睡前轻复习入口 + 次日优先昨夜字 |
| 心流（Flow） | 年龄静态适配为主 | 缺会话内滑动窗口难度环 |
| 具身认知 | 描红/拖拽有 | 缺手势/摆字（高成本，P2） |
| 随文识字 | 先识后读门控 | 缺阅读中点学生字轻量学 |

## 2. 三专业视角评估

### 2.1 心理学

**判断**：编码与存储骨架优秀；**提取练习不足是最大杠杆缺口**，且比「改造测步骤」叙事更大——因为被命名为「测」的步骤根本不是测验。

1. **主动回忆 > 再认**（Karpicke & Roediger）：应强化「见字 → 自说音/义 → 再翻验证」。
2. **生成效应**（Slamecka & Graf / Chi 自我解释）：字源后应允许儿童用自己的话生成联想，不评判对错。
3. **交错练习**（Rohrer & Taylor）：形近字混合练提升长期保持；短期更难属预期，需诚实文案与年龄门。
4. **元认知 / JOL**（Metcalfe）：自评可辅助 FSRS，但不惩罚、不羞辱。
5. **睡眠巩固**（Walker）：睡前轻编码 + 次日快速回顾是高价值时机，当前仅文案。

### 2.2 视觉设计

1. 大触控、mascot 引导、高对比整体合格。
2. 学习页仍有**信息过载**风险（部首/笔画/组词/例句/演变同屏）→ 建议渐进揭示：每步只留当前必要信息。
3. 象形演变已有「字形→图像」；可加强**笔画级视觉记忆钩子**（关键点高亮）。
4. 自由提取 UI 必须极简：正面只见字；反馈用色+动效+音效三重冗余（照顾色觉障碍）。

### 2.3 教育

1. 集中识字 + 认写分流 + 分级阅读，与部编理念对齐良好。
2. 「随文识字 / 以读促识」仍弱：门控是先识后读，缺语境中即时轻学。
3. 家长参与停留在软建议，缺「亲子共复习」可操作玩法。

## 3. 功能升级建议（按记忆机制分组）

### 建议 1【P0】低风险高频「自由提取」闪卡（测试效应）

- **依据**：主动回忆保持率显著高于再认。
- **功能**：复习中见字形 → 儿童先说/点「我会」→ 再翻到拼音/义验证。
- **改法**：复用 `flashcardEngine` 已有 recall 原子卡；`ReviewModule` 已 import 却主跑 `DrillEngine` —— **替换或并列**自由提取会话。3–4 岁降级为指认。
- **边界**：不改造 Step8「测」；不因说错惩罚（可再给一次或降为示范）。

### 建议 2【P0】形近字交错练习包（交错练习）

- **依据**：交错练习长期保持优于集中练习。
- **功能**：「找不同」式同屏多字快速判别（己/已/巳、人/入/八 等）。
- **改法**：`confusingChars` + `reviewConfused` + `sessionPlanner._interleave`；仅当配对字均已学过开放。
- **边界**：未学先混禁止；难度文案诚实（「有点难是正常的」）。

### 建议 3【P0】「字为什么长这样」自我解释（生成效应）

- **依据**：自我解释加深精细加工。
- **功能**：morph 剧场结束后开放提问「你觉得这个字像什么？」；语音或点选联想均可；**不评判**。
- **改法**：挂 `stepRecognize` / `stepPlay` 剧场关闭回调；可跳过。
- **边界**：建议 ≥5 岁开放；3–4 岁可只展示字源不问答。

### 建议 4【P1】「我会/我不会」自我评估（元认知）

- 复习入口三档自评 → 映射为 FSRS rating 辅助信号。
- `<6` 岁家长代评；结果不惩罚、只优化队列。

### 建议 5【P1】睡前复习 + 次日巩固（睡眠记忆）

- 接线 `microReviewScheduler`；入口挂 Map/复习/家长页，**不要**假设每日上限门禁页是庆祝页。
- 次日首启优先「昨夜学过的字」轻回顾。
- 仅温和引导，尊重作息。

### 建议 6【P1】实时动态难度（心流）

- 真正调用 `difficultyEngine.realtimeAdjust`（连对略升、连错略降并示范）。
- 难度有上下界，连错降级为示范而非惩罚。

### 建议 7【P2】手势/身体动觉识字

- 设备依赖高；无摄像头降级为空中比划动效。可选，非必须。

### 建议 8【P2】「以读促识」随文识字

- 绘本未学字可点出轻量字卡（约 5 秒内），不强制打断阅读流。

## 4. 优先级与复用摩擦

| 优先级 | 建议 | 成本 | 记忆收益 | 最佳复用路径 |
|--------|------|------|----------|--------------|
| **P0** | 1 自由提取闪卡 | 低 | ★★★★★ | `flashcardEngine` + `ReviewModule`（已 import） |
| **P0** | 2 形近字交错包 | 低–中 | ★★★★ | `confusingChars` + `reviewConfused` + interleave |
| **P0** | 3 自我解释 | 中 | ★★★★ | morph 关闭钩子（learnSteps） |
| **P1** | 4 JOL 自评 | 低 | ★★★ | Review 入口 + FSRS rating 辅助 |
| **P1** | 5 睡前/次日 | 低–中 | ★★★★ | 接线 `microReviewScheduler`（现死代码） |
| **P1** | 6 动态难度 | 中 | ★★★ | 接线 `realtimeAdjust`（现死代码） |
| **P2** | 7 具身识字 | 高 | ★★★ | 新玩法 |
| **P2** | 8 随文识字 | 中 | ★★★ | BookModule 热区 |

**P0 三项**仍是「低成本 × 高记忆收益」首批；但路径已按代码纠正（尤其建议 1 不碰 Step8）。

## 5. 实施原则（规划约束）

1. **数据层零新增优先**：建议 1/2/4 先玩法层验证，再考虑新字段。
2. **年龄护栏**：一律走 `getAge` / `getStepSequence`；自我解释 ≥5；JOL <6 家长代评。
3. **诚实性红线**：不评判自我解释；动态难度连错→示范；交错练习不误导「更难=你不行」。
4. **复活死代码优于新建引擎**：flashcard / microReview / realtimeAdjust / planDailySession。
5. **验证**：每项 ① 单测（调度/年龄门）② CDP 探针（交互推进）；记忆保留率 A/B 可选且需家长知情。
6. **与工程对照表分工**：工程债与诚实性修复以 `docs/现状对照表.md` 为准；本文只管**学习机制升级**，避免重复排「FSRS 未调用」类过时项。
