## 第 1 节 · 3-8 岁认知规律 → 工程约束映射

| 认知特点 | 设计含义 | 工程约束（硬指标） |
|---|---|---|
| 注意力持续短（3-4 岁 5-10 分钟；5-6 岁 10-15 分钟；7-8 岁 15-20 分钟） | 学习拆成 2-4 分钟微关卡，关卡间有明确“完成感” | 单关卡 ≤ 4 分钟；每 3 关强制一次“成就结算”；`eyeCareManager` 休息弹窗已具备，需按年龄调节间隔 |
| 依赖具象形象（前运算阶段） | 抽象概念必须图解：字源演变、情境图、实物联想 | 每个知识点必须有图形资产；无图不开课 |
| 偏好鲜艳色彩与高对比 | 主色高饱和暖色，功能区分色 | 对比度 ≥ 4.5:1（大字 3:1）；已修 emerald/amber-500→700 同类问题须全局治理 |
| 需要即时动态反馈 | 行为后 100ms 内必须有声/光/触反馈 | 点击响应 < 100ms；动效时长 200-400ms；触感与音效同步 |
| 前阅读期（不识字/少识字） | 界面以图形为主，文字为辅；所有指令可听 | 关键路径文字 ≤ 8 字；`data-speak` 全量覆盖；语音缺失时降级为“大图标 + 短文字” |
| 零惩罚（答错不羞辱） | 答错不扣分、不红叉，转为鼓励重试 | 答错反馈 = 温和抖动 + “再试一次”语音；不中断连击以外的负面计数 |

### H1 · 首屏「图形化任务地图」重构 【高】

**理由**：首屏是留存第一现场；当前地图按钮以文字标签为主，前阅读期儿童无法自主操作，必须依赖家长。

**现状与位置**：`mapHub/mapRender.js`（岛屿标签、地标卡、今日学练按钮 `btn-daily-quest`）、`mapHub/islandConfig.js`（主题配置）、`mapHub/dailyQuestModal.js`（任务弹层，并行会话建设中）。

**实现要点**
1. 地标卡改为 **大图形 + 单一动词图标**：图标 ≥ 72px，文字 ≤ 4 字且置于图形下方（作为辅助而非主识别）。
2. 今日学练按钮改为 **三枚图形进度章**（学/练/读），完成即点亮并播放“盖章”动画；数字仅以徽标小字呈现。
3. 岛屿切换用**图形标签**（森林🌳/小镇🏠/星空🚀 的位图图标），当前激活岛屿放大 1.1 倍 + 光晕。
4. 所有图形元素补 `data-speak`（儿童点击即听）。

**重构范围与影响**
- 范围：`mapRender.js` 地标卡与岛屿标签的模板段、`islandConfig.js` 新增 `iconKey/labelShort` 字段（新增不改旧字段）。
- 影响：视觉层改动，不涉及数据流；`mapEvents.js` 依赖 `.map-landmark-btn` 与 `data-mode`（**保持类名与 data 属性不变**即可零改动兼容）；涉及并行会话正在建设的 dailyQuestModal，**需与其错峰，仅改地标/岛屿段**。

**技术注意**：位图图标走 `gameIcons.js` 统一封装（自带 `data-fallback` 兜底）；新增图标需 webp + 同尺寸，避免布局抖动（CLS）；`cv-auto-large` 已有，长列表继续使用。

### H2 · 学字六步的图形化视觉语法 【高】

**理由**：学字是核心链路；六步中部分步骤文字说明偏多，儿童需家长陪同才能完成。

**现状与位置**：`learnSteps/`（stepMeta/Recognize/Read/Play/Prewrite/Trace/Practice/Test/Write）、`airTracePrompt.js`、`selfExplainPrompt.js`、`hanziEngine`（笔顺）、`prewriteEngine`（描红）。

**实现要点（每步固定“图形 + 动画 + 语音”三元组）**

| 步骤 | 图形表达 | 动画 | 语音 | 完成反馈 |
|---|---|---|---|---|
| 认（Recognize） | 大号象形图 → 楷体字 | 字形渐变过渡 400ms | “看，这个字像…” | 图形打勾 + 星 |
| 读（Read） | 喇叭按钮 + 声波波纹 | 波纹扩散循环 | 标准读音 ×2 | 麦克风图标待命 |
| 玩（Play） | 可拖拽的字形积木 | 拖拽弹性 + 吸附 | “把它拼起来” | 积木归位闪光 |
| 写（Prewrite/Trace/Write） | 田字格 + 笔尖粒子 | 逐笔点亮 + 粒子尾迹 | “跟我一起写” | 笔画全绿 + 盖章 |
| 练（Practice/Test） | 图形选择题卡 | 选中放大、错误轻抖 | 题干朗读 | 连击计数 + 彩带 |

**技术注意**
- 性能：描红 canvas 用 `requestAnimationFrame` 节流（已有 `prewriteEngine`）；粒子数量上限 ≤ 30/次，低端机按 `devicePixelRatio` 降级。
- 兼容：触屏 pointer events（已有 `touch-action: manipulation`）；描红需同时支持触摸与鼠标。
- 响应：书写轨迹本地立即回显（不得等待任何异步），评测/打分异步后置。
- 存储：单次学字结束才写 `charRecords`（避免高频 `save()` 全量序列化描红中间态）。

### H3 · 即时反馈系统集中化 【高】

**理由**：当前反馈分散在各模块（音效/粒子/触感各写各的），风格不统一且难维护；儿童对反馈一致性极敏感。

**现状与位置**：`soundEngine.js`（playSuccessSound/playWrong/playPop…已接 haptics 5 处）、`appHub/appFx.js`（粒子/彩带）、`utils/haptics.js`（新）。

**实现要点**
1. 新建 `feedbackHub.js` 统一出口：`feedback.ok()` / `feedback.tryAgain()` / `feedback.tap()` / `feedback.reward(kind)`，内部编排**声音 + 动效 + 触感**三通道。
2. 建立**动效时长预算**：微反馈 200ms、成功 400ms、奖励 800ms、页面切换 ≤ 300ms。
3. 零惩罚规则：答错只做 220ms 轻抖 + 温和语音 + 保留重试入口，**不出现红叉/负分/连击清零以外的惩罚**。
4. 降级：`prefers-reduced-motion` 或家长关闭时，动效降级为**透明度变化**，触感关闭，音效保留。

**技术注意**
- 响应：反馈触发必须**同步执行**（不等数据落库），落库异步；点击到反馈 < 100ms。
- 性能：彩带/粒子用 DOM 池（≤ 40 节点）或 canvas；动画期间避免触发布局的 CSS 属性（只用 transform/opacity）。
- 兼容：`navigator.vibrate` 在 iOS Safari 无效，须静默跳过（已在 `haptics.js` 处理）。
- 存储：反馈开关写入 `localStorage cathy_haptics`（已有），与家长设置联动。

**重构范围**：新增模块 + 逐步替换各模块直呼 `soundAndFX.playXxx()` 的反馈点（**分批替换，每批一个 hub，不一次性改动**），保持 `soundAndFX` API 不变。

### H4 · 语音优先指令层全量覆盖 【高】

**理由**：`data-speak` 覆盖 39%，剩余 61% 多为动态标签按钮，是前阅读期儿童自主操作的最后障碍。

**现状与位置**：`BaseModule._on`（自动接线 `data-speak`）、`SharedShell`、各模块模板。

**实现要点**
1. 补齐策略：**按模块分批改（Edit 单点）**，优先儿童高频路径（Learn/Review/Play/Book/Card）。
2. 动态标签使用模板表达式：`data-speak="去完成${t.title}的任务"`（渲染期求值，安全可行）。
3. 话术规范：儿童口语，≤ 12 字，动词开头（“点点看”“跟我读”“再试一次”）。
4. 与既有朗读 handler 冲突检查：**已绑定朗读逻辑的按钮不得再加 `data-speak`**（防双重播报——历史上已踩过）。

**技术注意**
- 兼容：`soundAndFX.speak` 在无本地语音服务时降级系统 TTS；不可用时静默（不阻塞交互）。
- 性能：避免同一时刻多个 speak 排队（已有 `PrioritySpeechQueue`）。
- 教训固化：**禁止批量改码脚本**（曾损毁两个文件），一律 id 锚定 + 唯一性断言 + 开标签尾部追加（本轮 18 处注入即用此法，验证通过）。

### M2 · 游戏区视觉语法与动效预算统一 【中】

**理由**：`playHub/*` 与 `playGames/*` 为多团队/多批次产出，风格与动效强度不一，低端机易掉帧。

**实现要点**：统一卡片圆角/描边/主色梯度；建立动效预算（同屏动画节点 ≤ 6，粒子总量 ≤ 40）；低端设备（`deviceMemory < 4` 或 `devicePixelRatio` 判定）自动降级。

### M3 · 家长中心图形化 【中】

**理由**：家长端文字密度高（`parentTabs.js` 800 行）；陪学家长常在碎片时间查看，需要“一眼看懂”。

**实现要点**：四维雷达（已落地）保留；说明性文案改为图示 + 进度条；关键操作（导出/清除/档案）保持门禁 + 图形确认。
**技术注意**：家长端不追求极简字号（成人使用），但需保证对比度与可点击区 ≥ 44px。

### M4 · 学习节奏自适应（防疲劳） 【中】

**理由**：注意力时长随年龄差异大，固定关卡长度易造成低龄儿童疲劳。

**实现要点**：按 `profile.age`（已有）+ 近 N 次表现（正确率/耗时/退出点）动态调整单关长度与休息间隔；连续错误 ≥ 2 自动降低难度或插入图形提示。
**技术注意**：调整仅改**本次会话**参数，不改写长期调度（FSRS 不受影响）；所有调整记录到学习日志供家长查看。

## 第 4 节 · 从启动到完成学习任务的完整交互流程

### 4.1 主流程（分步骤）

```
[启动]
 1  加载 index.html（CSP nonce 生效）→ app.js → appHub.init
 2  解锁音频（首次点击/触摸）→ 预热本地语音服务（失败静默降级）
 3  渲染 MapModule（图形地图 + 今日学练三枚进度章）
    ├─ 异常：无本地语音 → 静默降级系统 TTS；再失败 → 仅视觉反馈
    └─ 异常：上次崩溃/数据损坏 → storageManager 净化后进入；提示家长导出备份

[进入学习]（点击今日学练）
 4  dailyQuestModal 展示 3-5 个微关卡（学/练/读 图形章）
 5  进入单字六步：认 → 读 → 玩 → 写 → 练 → 测（按 age 裁剪）
    ├─ 每步 ≤ 40 秒，步骤间有“完成盖章”动画
    ├─ 异常：麦克风未授权 → 弹出家长门禁（micCompliance）；拒绝 → 跳过跟读，不阻塞
    ├─ 异常：描红超时/笔画偏差 → 温和提示 + 可跳过（不惩罚）
    └─ 异常：中途退出 → 已完成步骤写入 charRecords，未完成的步骤不写
 6  单字完成 → 奖励结算（星/币/触感）→ 回到任务链
 7  任务链全部完成 → 成就页（勋章/图鉴点亮）→ 复习到期队列提示
 8  推荐阅读（readingGatekeeper 就绪度排序）→ 绘本卡拉OK 伴读
 9  回到地图 → 今日学练章全部点亮 → 打卡 +1（家长中心雷达数据更新）

[家长路径]（点击家长中心图标 → 算术门禁）
10  查看四维画像/周报/设置（麦克风、触感、时长、专注模式）
    └─ 异常：导出/清除/导入 → 二次门禁（已实现）
```

### 4.2 异常与降级矩阵

| 异常 | 处理 | 用户可见 |
|---|---|---|
| 本地语音服务不可用 | 降级系统 TTS → 再降级纯视觉 | 无提示，功能不中断 |
| 麦克风拒绝/未授权 | `micCompliance` 门禁；拒绝则跳过跟读 | 家长可懂的中文提示 |
| 学习时长超限 | `eyeCareManager` 休息弹窗（家长可延长，需门禁） | 动画化护眼操 |
| 数据损坏 | `storageManager` 净化 + 加载兜底 | 提示导出备份 |
| 离线/断网 | 无影响（全本地） | — |
| 低端设备掉帧 | 动效降级（粒子/动画预算） | 无感 |
