## 1. 儿童汉字识字教学法（5-8岁）

### 核心研究发现

#### 1.1 认知发展规律与幼小衔接

**学术来源**：2025年《基于认知发展规律的幼小衔接阶段识字教学研究》

5-8岁儿童处于具体运算阶段前期到小学低年级，汉字学习必须遵循以下认知规律：

- **整体优先原则**：儿童先对汉字整体轮廓形成印象，再逐步深入到笔画细节。"鸟"字教学初期，儿童将其视为"一幅图"，这是正常认知阶段，不能强行提前要求部件辨析
- **音形义同步联结**：在音（拼音）、形（笔画结构）、义（字义）之间建立心理联系时，呈现"整体→孤立→联系"的认知变化轨迹
- **多感官参与原则**：视觉（字形观察）、听觉（发音）、触觉（手指描画）、动觉（身体动作演示字义）多通道输入可显著延长记忆保持时间

**教育神经科学发现**（来源：SDUT教育研究，2025）：

> 书写汉字是汉字学习过程中非常重要的一项……在教学过程中注重引导学生认识汉字的字形结构、语义和语音等要素，结合汉字学习的认知能力……通过汉字书写提高汉字认知水平。

#### 1.2 构形理据与形声字教学

**学术来源**：申世琪等，2025，《教育科技前沿》

形声字占汉字总量80%以上，是小学低年级识字教学的核心：

| 教学策略 | 方法 | 效果 |
|---------|------|------|
| 字理故事 | 讲述造字故事建立形-音-义关联 | 提高记忆效率300% |
| 理据儿歌 | 偏旁口诀歌谣朗朗上口 | 提升部件意识建立速度 |
| 循形辨义 | 通过形状差异区分形近字 | 减少形近字混淆错误率 |

#### 1.3 正字法意识发展时间表

**学术来源**：汉语儿童正字法意识发展研究（心理学期刊）

| 年龄 | 正字法意识水平 | 教学重点 |
|------|--------------|---------|
| 学前（5-6岁） | 整字和部件形态意识萌芽 | 象形字整体认读 |
| 一年级（6-7岁） | 部件位置意识大幅提高 | 部首辨析、形近字区分 |
| 二年级（7-8岁） | 笔画形态意识建立 | 笔顺规范、间架结构 |
| 三年级（8-9岁） | 正字法意识持续发展 | 同义/反义、一词多义 |

## 2. FSRS算法最新研究（2025-2026）

### 核心算法版本对比

| 版本 | 参数数量 | 核心改进 | 生产状态 |
|------|---------|---------|---------|
| FSRS v3 | 13 | 基础稳定-难度-可检索性模型 | 稳定 |
| FSRS v4 | 17 | 遗忘曲线公式改进 | 稳定 |
| FSRS-4.5 | 17 | 遗忘曲线公式变更 | 稳定 |
| FSRS-5 | 19 | 闭式间隔数学优化 | 稳定 |
| **FSRS-6** | **21** | **可训练衰减参数 w20 + 同日复习改进** | **当前生产标准** |
| FSRS-7 | 8（遗忘曲线） | 分数间隔 + 实时同日复习预测 | 研究中，非发布版 |

### FSRS-6 关键技术细节

**遗忘曲线公式**（来源：yazu.app，2026-07更新）：
```
R(t, S) = (1 + factor · t/S)^(−decay)
factor = 0.9^(−1/decay) − 1
decay = w20 (默认 0.1542; factor ≈ 0.980346)
```

**关键特性**：
- **可个性化衰减参数 w20**：FSRS-5对所有人用相同遗忘曲线形状；FSRS-6通过优化让不同用户有不同的衰减曲线形状
- **同日复习处理**：`S' = S · exp(w17·(G − 3 + w18)) · S^(−w19)` — 但FSRS-6在同日内无法区分1分钟后和10小时后的复习
- **间隔计算闭式解**：`I = (S / factor) · (R_d^(−1/decay) − 1)`

**基准测试结果**（来源：open-spaced-repetition/srs-benchmark，9999名Anki用户数据）：

| 算法 | LogLoss | RMSE-bins | AUC |
|------|---------|-----------|-----|
| SM-2 | 0.3726 | 0.0838 | 0.6853 |
| FSRS-4.5 | 0.3726 | 0.0838 | 0.6853 |
| FSRS-5 | 0.3560 | 0.0741 | 0.7011 |
| **FSRS-6（每用户优化）** | **0.3460** | **0.0653** | **0.7034** |

## 3. 闪卡学习最佳实践（SM-18 / Anki / SuperMemo）

### 核心原则

#### 3.1 最小信息原则（Minimum Information Principle）

**来源**：SuperMemo "Twenty Rules of Formulating Knowledge"

闪卡有效的唯一最重要原则：**一张卡片 = 一个独立知识单元**

| 好闪卡 | 坏闪卡 |
|--------|--------|
| "鸟字怎么读？" → "niao3" | "鸟字：niao3，指天上的飞禽，有翅膀"（太多信息） |
| "'目'字和'木'字有什么不同？" → "目像眼睛，木像树木" | "目字和木字的区别是什么？"（太开放，无法客观评分） |

#### 3.2 主动回忆 vs 被动识别

研究反复证明：**主动回忆（recall）比被动识别（recognition）的记忆效果强3-4倍**。

- **好**：给出拼音 `niao3`，问"这是什么字？"（主动）
- **坏**：显示汉字"鸟"，问"这个字读什么？"（被动识别）

**凯茜识字当前问题**：
- LearnModule Step3 朗读评测实际上是在测试主动回忆（说出字的发音）——这是正确的
- 但 Step4 练字游戏（气球射击）是字形识别，不是回忆——应该增加"听音写汉字"的题型

#### 3.3 Cloze Deletion（填空题）的正确用法

**来源**：SuperMemo "Twenty Rules"

填空题（凯茜的"词语填空"、"句子填空"）有效的关键：
- 空白处必须**只有一个正确答案**，不能有多个可能的填入词
- 当前 DrillEngine 的 `sentence_fill` 题型的 sentence 如果有多个可能的汉字填入，就会导致无法客观评分

```javascript
// 当前 drillEngine.js 第 40 行 sentence_fill 题型
// 需要在题目生成时验证空格的唯一性：
function validateClozeUniqueness(sentence, char) {
  // 用正则替换掉目标字，检查是否还有其他可能的候选字
  // 例如 "我喜欢(_)" → 只允许"你"或"她"，不允许"红"或"天"
}
```

#### 3.4 间隔重复在闪卡中的最佳实践

| 实践 | 推荐做法 |
|------|---------|
| 新卡片间隔 | 1分钟 → 10分钟 → 当天复习 |
| 复习频率 | 目标留存率90%时，间隔约为当前稳定性的1.1倍 |
| 卡片难度分级 | 对3-4岁儿童，Hard评级应触发更短间隔而非更长间隔 |
| 学习极限 | 每日新卡上限：5-8岁儿童建议5-8张/天，避免认知过载 |

## 4. 儿童学习动机与游戏化

### 元分析核心发现

**来源**：Frontiers 2026年元分析（90项干预研究）+ MDPI 2024年系统综述（9项研究综合）

#### 4.1 游戏化效果的真实幅度

| 结果维度 | 效应量（SMD） | 统计显著性 |
|---------|--------------|---------|
| **动机与情感参与** | **1.13**（大效应） | 显著 |
| 学业表现 | 0.30-0.61（中小效应） | 条件显著 |
| 行为参与 | 变化大，不一致 | 不显著 |

**关键结论**：游戏化对**动机**的效果是确切的（大效应量），但对**学业表现**的影响是条件性的——取决于游戏化设计的质量。粗糙的奖励叠加不能自动带来学习效果提升。

#### 4.2 有效游戏化的5个设计原则

**来源**：MathCraft（白玫瑰数学课程，UK）+ Teach Your Monster Reading For Fun

| 原则 | 具体做法 | 凯茜识字现状 |
|------|---------|------------|
| **1. 学习即游戏机制** | 每一个游戏操作背后就是真实课程内容 | 部分满足：象形字源物理交互是真正的学习内容，但"射击气球"与字形认知的关联较弱 |
| **2. 叙事与身份认同** | 儿童创建一个角色，在游戏世界中冒险 | 未满足：凯茜识字的"凯茜"是外部引导角色，不是儿童的自创角色 |
| **3. 清晰目标+即时反馈** | 每30秒内有1次成功反馈 | 满足较好：Step流程每步都有进度反馈 |
| **4. 适应性挑战** | AI根据表现动态调整难度 | 未满足：5种游戏场景无难度自适应，同一个字玩哪局都一样 |
| **5. 社会化互动** | 亲子共同参与、家庭排行榜 | 部分满足：有亲子任务卡但未集成到核心学习流 |

#### 4.3 MathCraft 的"隐形课程"设计

MathCraft（UK，5-14岁免费数学RPG）的核心理念值得借鉴：
- **不是"做题披上游戏外衣"**，而是"学习内容本身就是游戏操作"
- 例如：儿童不是在"计算分数"，而是在"分配战利品"——游戏机制本身就需要做真实的分数运算
- 对应凯茜识字：儿童不是在"答题"，而是在"喂食小宠物"——只有答对字音题才能获得食物

### 对凯茜识字的工程建议

**建议A：将奖励系统从"外在激励"升级为"内在动机"**

当前凯茜识字的激励链条是：
```
学完字 → 获得金币/星星 → 用金币浇水/装扮
```
问题：儿童会因为"想要金币"而学习，不是真正因为"对汉字感兴趣"而学习。当金币耗尽时，学习动力归零。

建议改为：
```
读准发音 → 凯茜精灵的反应更丰富 → 凯茜解锁新表情/新故事
```
（内在动机：探索欲、成就感、社会认同）

```javascript
// 在 LearnModule 中增加"凯茜反应积累"系统
const cathyReactionProgress = {
  [charId]: {
    correctPronunciations: 0, // 连续正确发音次数
    expressions: ['neutral', 'happy', 'excited'], // 解锁的表情
    storyUnlocked: false
  }
};
// 当连续3次正确发音时，凯茜解锁一个专属故事片段
// 当完成5个字后，凯茜的动画效果升级
```

**建议B：消除"游戏化噪音"**

研究发现（Toca Boca、Sago Mini vs. Roblox的对比）：
- **安静的视觉设计**（柔和色调、无闪烁）→ 更高的学习专注度
- **过度刺激**（弹窗、积分滚动、数值跳动）→ 儿童将app视为老虎机，降低对学习内容的注意力

凯茜识别的视觉噪音检查：
- ❌ 粒子动画（_sparkleAt）过于频繁，每次点击都有视觉爆发
- ❌ 金币飞行动画（triggerCoinFly）在每一步学习后触发
- ✅ confetti只用于真正重要的成就节点（可保留）
- ✅ Khan Academy Kids采用柔和色调和克制的动画，是正确方向

## 5. 触屏手写输入最佳实践

### 核心研究发现

#### 5.1 手指 vs 手写笔：谁更优？

**来源**（按效果排序）：

1. **手指书写 > 手写笔**（对于4-5岁幼儿）
   - 来源：Patchan & Puranik (2016)，《Using tablet computers to teach preschool children to write letters》
   - 原因：触屏表面摩擦力低+手写笔精细控制要求高，反而增加运动负担
   - 内在触觉反馈（intrinsic feedback）更丰富：手指触摸屏幕的物理感提供了更好的本体感觉反馈

2. **铅笔书写 > 手写笔**（对于5-7岁有一定精细动作基础的儿童）
   - 来源：PMC 2020研究《Literacy Training of Kindergarten Children With Pencil, Keyboard or Tablet Stylus》
   - 触屏表面摩擦力低，增加精细运动控制难度
   - 但触屏书写 + 即时视觉反馈 > 纸张书写（当有AI笔顺实时纠错时）

3. **即时外在反馈（extrinsic feedback）无额外收益**
   - 研究发现：带AI即时纠错的触屏书写并不比无声反馈的触屏书写更有效
   - 儿童更多依赖内在触觉反馈自主调整

#### 5.2 Letter School 应用的设计原则（经研究验证有效）

来源：Rellensmann et al., 2020, "Using a handwriting app leads to improvement in manual dexterity"

**四步教学法**（凯茜的 prewriteEngine 应该完全对齐）：

| 步骤 | 内容 | 凯茜 prewriteEngine 对应 |
|------|------|----------------------|
| 1. 观察 | 观看字形动画演示 | ✅ demoAllStrokes() |
| 2. 描起点终点 | 触摸字形描摹轨迹 | ✅ traceLine/traceCircle |
| 3. 动作演示 | 动画展示如何运笔 | ❌ **缺失** |
| 4. 独立书写 | 无辅助独立完成书写 | ✅ HanziEngine 描红后独立书写 |

**步骤3缺失**：当前 prewriteEngine 没有"观看运笔动作动画演示"的环节，应该添加。

#### 5.3 触屏交互的儿童UX研究关键发现

**来源**：Taps, Swipes, and Screens (ACM DIS 2025, India研究）

| 儿童年龄 | 推荐交互 | 避免 |
|---------|---------|------|
| 3-4岁 | 单点（tap）、短拖动（short drag） | 双指捏合、滑动手势 |
| 5-6岁 | 可引入双指手势 | 复杂多步手势 |
| 6-8岁 | 复杂交互+手势组合 | 纯文字指令（改用图标+语音） |

**交互反馈时效要求**：
- 点击确认反馈：**< 150ms**
- 内容转场完成：**< 300ms**
- 若有不可避免的延迟：**显示 anticipatory animation**（如加载动画）维持注意力

**触屏热区问题**：
- 屏幕**左下角**和**复杂控件周围**是儿童最高犹豫区
- 建议：主要操作按钮放在屏幕中央偏右，避开左下角
