## 二、改造原则（儿童优先设计准则）

1. **语音优先于文字**——目标用户是前阅读期儿童；
2. **大目标、强反馈、零惩罚**——答错不扣分不红叉，只鼓励重试；
3. **一次一件事**——单屏单一焦点，控制认知负荷；
4. **成人可配置、儿童不可误触**——一切家长功能过算术门禁；
5. **隐私默认最小化**——数据不出设备，采集必告知。

### P0-1 设计 Token 化：儿童色板 + 字号刻度 + 48px 触控标准
- **价值**：一致的大字号/大色块/高对比是儿童 UI 第一要素，也是后续所有改造的地基；现状样式散落、无法全局调优。
- **现状与位置**：`tailwind.config.js`（无 colors 扩展）、`style.css`、`index.html`（theme-color `#FF6B00`）、`manifest.json`（background `#0f172a` 深色——与儿童产品偏亮的调性不符，建议评估换暖色）。
- **实现方向**：`theme.extend.colors` 定义语义色板（primary 橙 + 快乐绿/天空蓝/阳光黄 + 语义 success/warning）；`fontSize` 定义 `kid-body:18px`、`kid-title:28px`、`kid-hero:88~120px`（汉字卡）；全局按钮最小尺寸 token `touch-min:48px`（现有 40px 伪元素方案在 `_touch_audit` 基础上统一升级）；正文行高 ≥1.6。
- **验收**：`grep` 无 `text-\[(1[0-5]px)\]` 级过小字号；主色仅来自 token；`tools/_touch_audit` 全模块 ≥48px。

### P0-2 全局「语音指令层」（语音优先）
- **价值**：**识字 App 最大的可用性悖论**——不识字的孩子看不懂文字指令。语音化后 3-4 岁儿童可完全独立使用，直接影响留存。
- **现状与位置**：`neuralVoice.js`(601，本地 127.0.0.1:8766 AI 语音) + `soundEngine.js`(1595) 管线已就绪；`BaseModule._on` 是全模块统一事件挂接点；`SharedShell.mountGameShell` 是统一壳。
- **实现方向**：① `_on` 支持 `data-speak` 声明，元素获得焦点/按下时自动 TTS 朗读其语义；② 每个模块的引导文案配 🔊 按钮（语音可重听）；③ 关键流程（学习步骤切换、答错鼓励）由语音而非文字承担；④ 语音不可用时降级为大图标+短文案。
- **验收**：抽查 20 个高频按钮均可触发朗读；断网/本地语音未启动时不阻塞交互。

### P0-3 无障碍与动效安全网
- **价值**：覆盖特殊需求儿童（ADHD/视觉障碍），家长信任度与应用商店审核加分。
- **现状与位置**：aria 覆盖稀疏（11 处 label）；reduced-motion 仅 3 文件；`soundAndFX.triggerConfetti` 等强动效遍布。
- **实现方向**：① 所有可交互元素补 `aria-label`/`role`（集中在各模块模板字符串）；② 全局 `@media (prefers-reduced-motion: reduce)` 一刀切关闭 confetti/视差/无限动画（bounce-slow 等）；③ 用 contrast-audit 思路跑一次对比度审计（儿童大字号下 AA 门槛 3:1）；④ `aria-live` 补到答题结果播报。
- **验收**：Lighthouse a11y ≥ 90；reduced-motion 下无无限动画。

### P0-4 触感反馈（多通道强化）
- **价值**：低龄儿童对触觉反馈的感知强于视觉/听觉，答对"嗡"一下是即时奖励。
- **现状与位置**：`navigator.vibrate` 0 处；反馈集中点在 `soundAndFX`（playSuccessSound/playPop/playVictoryFanfare）与 `appHub/appFx.js`。
- **实现方向**：封装 `haptic("success"|"error"|"tap")`（success=短双震 30+60、error=单长 200、tap=15），在 soundAndFX 对应方法内同步调用；家长中心加开关；iOS 不支持自动跳过（能力检测）。
- **验收**：Android Chrome 答题有差异化震动；开关关闭后静默。

### P0-5 麦克风与语音数据合规（隐私 P0）
- **价值**：`pronunciationEval.js:451-494` 使用 `getUserMedia` + `MediaRecorder` 录制 3-6s 音频并生成 Blob 回放——**儿童生物特征数据**，属《儿童个人信息网络保护规定》敏感项；不合规是下架级风险。
- **实现方向**：① 首次使用发音评测前弹**家长门禁 + 用途声明**（"仅在本设备本地评测，不上传"）并持久化同意记录；② 录音时屏幕显示 🎙️ 录制中指示（现有 UI 若无则补）；③ 录音 Blob 用完即弃（核查是否持久化，若缓存需限期清理）；④ 家长中心加「关闭语音评测」总开关；⑤ 写一页《数据清单》文档（存什么、存哪、谁可看、如何删）。
- **验收**：未过门禁时评测入口不可达；清单文档入库 `docs/`。

### P0-6 家长门禁覆盖补全
- **价值**：门禁是"儿童不可误触"原则的执行器；现状仅 2 个调用点。
- **现状与位置**：`parentGate.js` 调用点仅 `appNavigation.js:149`（进家长中心）与 `eyeCareManager.js:185`（护眼解锁）。
- **实现方向**：逐一核对敏感操作——档案新增/删除、数据导出/导入（`storageManager` 已有 import/export）、时长与难度配置修改、商店大额消费（可选）——全部过 `showParentGate`；门禁题支持难度档位（加法→乘法）。
- **验收**：输出《敏感操作×门禁覆盖对照表》并全部 ✅。
