## B. 教学法维度分析

### B1. 字形教学（5.5/10）

**做得好的：**
- LearnModule Step1 象形蜕变（甲骨文→小篆→楷书），符合儿童具象思维
- CardModule 部首字典（含造字本源解说）
- HanziEngine 田/米字格双模式 + 年龄自适应（<5岁强制田字格）

**严重缺陷：**
- **字符数据字形分析缺失**：1490字中大量缺少 `strokeRules`（笔顺规则）、`morphemicComponents`（义符/声符拆分）、`variantForms`（异体字）。characters.js 字形数据结构极不统一
- **笔顺评测过宽**：`hanziEngine.js` 第 310-360 行 `checkTraceAccuracy()` 仅用端点距离判定，任何能"画到位置"的轨迹都会被接受，5-7岁儿童会养成错误笔顺习惯
- **形近字干扰无针对训练**：LearnModule Step4 练的干扰项是随机4选1，未利用 `errorProfiles.confusedPairs` 做针对性形近字训练

### B2. 字音教学（6/10）

**做得好的：**
- PinyinModule 四声调过山车，音调可视化优秀
- neuralVoice 本地 TTS（zh-CN-XiaoxiaoNeural，MOS 4.10），无网络依赖
- pronunciationEval 音素级相似度计算，包含声母/韵母混淆矩阵

**严重缺陷：**
- **Step3 读字评测结果未写回**：LearnModule.js 第 1775 行 `ebbinghausManager.completeCharacter(char.id, 3)` 硬编码3星满分，**从未使用 `pronunciationEval` 的实际评分结果**（第 1050 行 `score` 变量只用于展示，不参与进度）
- **同音字教学空白**：characters.js 的 `words` 数组只有组词，没有同音字辨析（如"木/目/牧"）
- **轻声/儿化无覆盖**：pinyinList 有轻声变调数据但拼音模块未使用

### B3. 字义教学（4/10）

**做得好的：**
- BookModule 绘本阅读，字义通过情境习得
- CardModule 词组卡片 + 例句朗读

**严重缺陷：**
- **字符库字义数据贫乏**：大量汉字只有1-2个例词，无一词多义覆盖，无反义词/同义词字段
- **字义评测完全缺失**：7步学习流中无任何字义理解题目（选字义/配图/连线均无），学习效果无法量化
- **象形字源蜕变无认知引导**：Step1 展示甲骨文但无"这是什么的形状？为什么变成现在这样？"的追问

### B4. 字用教学（3.5/10）

**做得好的：**
- BookModule 造句环节（间接覆盖）
- 家长端字帖打印（手写迁移）

**严重缺陷：**
- **字用练习零覆盖**：LearnModule 7步中"写"只做笔顺描红，无**语境造句/看图说话/情景选择**等真正字用练习
- **同形异义/一词多义无区分**：无任何基于语境的字义选择题
- **成语/古诗与汉字脱节**：poems.js 存在但未被任何学习流引用

### ★★★ 第1名：FSRS复习调度从未触发（学习效果无法维持）

**位置：** `src/utils/fsrsScheduler.js` 全文 + `src/utils/ebbinghaus.js` 第 8-9 行  
**现状：**

```javascript
  this.save();
  eventBus.emit(EVENTS.CHAR_LEARNED, { charId, stars });
}
```

### ★★ 第5名：hanziEngine 笔顺判断算法粗糙

**位置：** `src/utils/hanziEngine.js` 第 310-360 行 `checkTraceAccuracy()`

**现状：**
```javascript
checkTraceAccuracy(userPath, expectedStroke) {
  // 仅比较端点 Euclidean 距离
  const startDist = euclidean(userPath[0], expectedStroke.start);
  const endDist = euclidean(userPath[userPath.length-1], expectedStroke.end);
  const startOk = startDist < this.tolerance;
  const endOk = endDist < this.tolerance;
  // 中间轨迹完全不验证！
  return startOk && endOk;
}
```

**后果：** 5-7岁儿童可以从任意中间路径绕过笔画走向要求，长期养成错误笔顺后极难纠正

**改进：**
```javascript
// hanziEngine.js 新增 strokeDirectionCheck() 方法：
strokeDirectionCheck(userPath, expected) {
  if (userPath.length < 3) return false;
  
  // 计算用户轨迹的平均角度变化
  const angles = [];
  for (let i = 1; i < userPath.length - 1; i++) {
    const dx = userPath[i+1].x - userPath[i].x;
    const dy = userPath[i+1].y - userPath[i].y;
    angles.push(Math.atan2(dy, dx));
  }
  
  // 期望笔画角度（从 start 到 end）
  const expectedAngle = Math.atan2(
    expected.end.y - expected.start.y,
    expected.end.x - expected.start.x
  );
  
  // 允许 60° 偏差
  const avgAngle = angles.reduce((a, b) => a + b, 0) / angles.length;
  const angleDiff = Math.abs(avgAngle - expectedAngle) * (180 / Math.PI);
  return angleDiff < 60;
}

// 在 checkTraceAccuracy() 中追加：
return (startOk && endOk) && this.strokeDirectionCheck(userPath, expectedStroke);
```

## E. 总体评价

### 优点（必须保留的设计）
1. **五步学习流设计**：玩→认→读→练→写→测的闭环逻辑清晰，年龄自适应（<5岁跳过描红）符合教育学
2. **PinyinModule 是全应用教学法最完备的模块**：四声调可视化+声韵碰撞+防混淆提示，真正帮助儿童建立拼音认知
3. **neuralVoice 本地化架构优秀**：无需网络的 TTS 合成 + LRU 缓存 + DSP 处理，离线可用性极高
4. **BaseModule 生命周期管理规范**：所有模块继承统一清理，避免内存泄漏
5. **PWA + 离线缓存完善**：Service Worker 37文件预缓存，适合儿童设备使用场景

### 最需要改变的三件事
1. **让 FSRS 真正运行**：这是让儿童"学会并记住"的核心算法，当前等于没有
2. **把评测结果真正用起来**：Step3 读字的评分必须写回进度，否则整个评测是表演
3. **补全字义/字用数据**：当前characters.js 的数据结构只能支持字形和字音教学，字义和字用几乎是空白，这是限制应用教学效果的最后一公里
