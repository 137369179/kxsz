## 二、改进方案总览（按优先级）

### 🔴 P0 — 必须立刻修复（教学核心失效）

#### P0-1：FSRS 真正运行起来

**位置**：`src/utils/fsrsScheduler.js` + `src/utils/ebbinghaus.js`

**现状**：FSRS 算法实现完整但 0 调用，复习队列=随机 5 题。

**改造**：

1. **升级到 FSRS-6**（21 参数标准），替换简化 v3：
   - 用闭式解 `I = (S / factor) · (R_d^(−1/decay) − 1)`
   - 引入个性化 `w20`（遗忘曲线衰减参数）
   - 支持同日复习区分（学习后立即练习 vs 跨日复习）

2. **ebbinghausManager.completeCharacter() 真正调用 FSRS**：
   ```javascript
   completeCharacter(charId, stars) {
     const rating = starsToFSRSRating(stars); // 3→EASY, 2→GOOD, 1→HARD, 0→AGAIN
     const prev = this.progress.charRecords[charId] || initFSRSRecord(charId);
     const updated = scheduleFSRS_6(prev, rating); // 真用 FSRS-6
     this.progress.charRecords[charId] = updated;
     this.save();
   }
   ```

3. **ReviewModule.initQueue() 改用真实 FSRS 队列**：
   - 70% 权重：FSRS 到期字
   - 20% 权重：错误档案中高频错字
   - 10% 权重：新字预热

**预期**：30 天记忆保持率 +35%

---

#### P0-2：朗读评测分数写回进度

**位置**：`src/components/LearnModule.js` 第 1050-1110 行 + 1775 行

**现状**：第 1050 行解析真实 `res.totalScore`，第 1090 行仅展示用，第 1775 行硬编码 3 星写回。

**改造**：

1. **`_showEvalResult()` 保存最后结果到实例**：
   ```javascript
   _showEvalResult(stage, res) {
     this._lastEvalResult = res; // 持久化结果
     this._lastEvalStage = stage;
     // ... 原有 UI 逻辑
   }
   ```

2. **完成回调读取真实评分计算 stars**：
   ```javascript
   const actualStars = calculateStarsFromEval(this._lastEvalResult);
   ebbinghausManager.completeCharacter(char.id, actualStars);
   ```

3. **`calculateStarsFromEval()` 评分规则**：
   - totalScore ≥ 85 → 3 星（EASY）
   - 60-84 → 2 星（GOOD）
   - 40-59 → 1 星（HARD）
   - < 40 → 0 星（AGAIN，触发 10 分钟再学习步）

**预期**：评测结果真实影响复习调度，薄弱字得到更多关注。

#### P0-3：补全字义/字用数据

**位置**：`src/data/characters/` 各阶段文件

**现状**：80% 缺 `meanings/synonyms/antonyms/contextExamples`。

**改造**：

1. **定义标准 Schema**（`src/data/charactersSchema.js`）：
   ```javascript
   export const CHAR_SCHEMA = {
     required: ["id", "char", "pinyin", "radical", "strokeCount", "strokes", "pinyinTone"],
     recommended: ["words[3+]", "sentence", "compoundChars"],
     // 字义扩展（按认知阶段分层）
     cognitiveStage: {
       preschool: "整体象形字描述（5-6 岁）",
       grade1: "部件辨析+同音字辨析（6-7 岁）",
       grade2: "一词多义+常见错误辨析（7-8 岁）",
     },
     meanings: ["多义项数组，每项含 sense/explanation/example"],
     synonyms: ["同义词（按义项分组）"],
     antonyms: ["反义词（按义项分组）"],
     contextExamples: ["情境例句（带场景标签：家庭/学校/自然）"],
     commonMistakes: [{ confusionChar, confusionType, hint }],
     homophoneGroup: ["同音字组（含辨析提示）"],
   };
   ```

2. **分级补全**：
   - 立即：阶段一 200 字完整数据（手写）
   - 短期：阶段二 400 字（人机协作 + AI 生成）
   - 中期：阶段三 890 字（程序化生成框架）

**预期**：字义/字用练习覆盖率从 0→80%。

#### P0-4：HanziEngine 笔顺方向角验证

**位置**：`src/utils/hanziEngine.js` 第 310-360 行

**现状**：仅端点距离判定，绕路轨迹可通过。

**改造**：

1. **新增 `strokeDirectionValidator()`**：
   - 计算用户轨迹平均方向角

   ```javascript

   ```

**预期**：养成正确笔顺习惯，5 年级不再因笔顺失分。

## 四、关键设计原则（不可妥协）

### 4.1 一张卡片 = 一个独立知识单元
- 来源：SuperMemo "Twenty Rules"
- 不在 LearnModule 中混合"读字 + 字义 + 写字"，每步只测一个维度

### 4.2 主动回忆 > 被动识别
- 每节课至少 50% 题目是"听音写汉字"（主动），而不是"看字选字"（被动）
- "主动回忆比被动观看记忆深 4 倍"

### 4.3 字形/字音/字义/字用 四维闭环
- 字形：象形蜕变 + 笔顺（5-7 岁重点）
- 字音：拼音 + 朗读评测（关键，不能形同虚设）
- 字义：补全数据 + 部件辨析（6-7 岁重点）
- 字用：语境造句 + 看图说话（7-8 岁重点）

### 4.4 视觉安静度 > 装饰丰富度
- 参考 Khan Academy Kids / Sago Mini
- 粒子动画 ≤ 30 个总量
- 金币飞行仅主成就触发

### 4.5 5-7 岁儿童的 3-5 分钟单次学习时长
- 拆微课、分次完成
- 不强制连续完成 7 步

### 4.6 FSRS 个性化是核心
- 不要硬编码复习间隔
- 让算法基于儿童实际表现调整
